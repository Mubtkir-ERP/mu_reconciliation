# MU Reconciliation (مطابقة مبيعات مدى والبنوك)

تطبيق متكامل لنظام ERPNext / Frappe مطور خصيصاً بواسطة **Mubtkir** (https://www.mubtkir.com) لمطابقة مبيعات شبكة مدى وموازنات الأجهزة اليدوية مع كشوف الحسابات البنكية.

---

## 🌟 الميزات الرئيسية:
1. **سجل أجهزة مدى (Mada Terminal):**
   - يدعم الفروع المتعددة وتعدد الأجهزة لكل فرع (3 إلى 4 أجهزة للفرع الواحد).
   - زر سريع ومرن لتسليم واستبدال الأجهزة بين الموظفين والسائقين مع سجل تتبع كامل (`assignment_history`).
2. **سند موازنة مدى (Mada Settlement Entry):**
   - تسجيل موازنات الأجهزة يدوياً من الإيصال الورقي أو استيرادها.
   - زر ذكي لجلب أجهزة الفرع تلقائياً لتسريع الإدخال اليومي.
3. **مطابقة كشف الحساب البنكي (Mada Bank Reconciliation):**
   - قارئ شامل يدعم ملفات الإكسل بكافة صيغها (`.xls`, `.xlsx`, `.csv`) وملفات الـ `PDF`.
   - محرك مطابقة ذكي ثنائي يعتمد على: `رقم الجهاز (TID) + تاريخ الحركة + المبلغ`.
   - كشف فوري بالألوان:
     - 🟢 **مطابق ومودع بالبنك**.
     - 🔴 **مبالغ مفقودة أو معلقة بالبنك** (مسجلة بالنظام ولم تنزل بالحساب لمطالبة البنك بها).
     - 🟡 **إيداعات بنكية بدون موازنة**.
4. **توليد قيد العمولات البنكية المجمعة للأسبوع:**
   - بضغطة زر واحدة ينشئ ويرحل قيد يومية محاسبي بخصم عمولات مدى والضريبة من حساب البنك إلى حساب المصروف.
5. **تقرير حالة المبالغ (Mada Reconciliation Status Report):**
   - تقرير تحليلي لمتابعة كافة الأجهزة والفروقات.
